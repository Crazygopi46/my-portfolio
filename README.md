## 🚀 Quick Start / Local Setup

To preview or run this portfolio locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Crazygopi46/gopi_portfolio.git
   ```

2. **Navigate into the project folder:**
   ```bash
   cd gopi_portfolio
   ```

3. **Open in browser:**
   - Double-click `index.html` to open it directly in any browser.
   - Or run with Live Server (VS Code extension / `npx serve .`).
